# 当前进度与后续工作

## 已完成

- 固定 QQBridge 基线的可检查、可回滚安装器和兼容补丁。
- 按会话混合后端及纯 Dot 模式，纯模式不创建 DSH 客户端。
- 六个受限 MCP 工具，分页读取、稳定领取/发送 ID、显式收尾。
- Events 目录、精确过滤、订阅去重、回调验证、签名投递和有界重试。
- 加密 SQLite 保存订阅、outbox、运行引用、发送预留和诊断。
- HTTP / stdio 入口、官方隧道连接脚本和可选 Windows 管理器。
- 工具/事件元数据的独立诊断和代理虚拟 DNS 地址兼容。
- 真实 Dot 事件触发及一次私聊自动回复完整闭环，见 [验证记录](verification.md)。

## 保留的边界

初版工具只提供纯文本收发与收尾。QQBridge 运行账本仍在进程内；重启后未确认的发送必须核实。单机私有连接不能直接扩展为多用户 OAuth 服务。

## 下一步

1. 设计能与 QQBridge 已读水位一致恢复的持久化运行账本及人工核实工具。
2. 按实际需求增加图片、语音和贴纸工具，同时保留会话范围和发送校验。
3. 提升会话范围、事件订阅和插件元数据变动的同步体验。
4. 如需多用户部署，先设计独立身份、授权、存储和订阅隔离。

每项扩展分别记录离线测试、固定基线组件测试和真实账号证据，不将其中一种验证代替另一种。
